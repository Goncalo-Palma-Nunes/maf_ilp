# maf_ilp
An Integer Linear Program model for the Maximum Agreement Forest problem between two rooted binary phylogenetic X-trees. This implementation is based on the model by [1].

References:

[1] Yufeng Wu, A practical method for exact computation of subtree prune and regraft distance, Bioinformatics, Volume 25, Issue 2, January 2009, Pages 190–196, https://doi.org/10.1093/bioinformatics/btn606
